# گام‌های بعدی با TheTrueTrade

## وضعیت تحویل

بستهٔ preview مستقل پنل با Next.js ازپیش‌ساخته‌شده، ابزار ساخت archive و Compose آماده است. TheTrueTrade در فرم اتصال به‌عنوان حساب فیوچرز پیش‌فرض اضافه شده است. کلید هر مشتری رمز‌شده ذخیره می‌شود و worker موجود، GETهای حساب را با همان کلید اجرا می‌کند. هیچ کلید عمومیِ مدیر جای کلید مشتری استفاده نمی‌شود.

مقادیر گزارش‌نشده مانند مارجین قفل‌شده، قیمت لحظه‌ای، اهرم و PnL پوزیشن با صفر یا عدد ساختگی پر نمی‌شوند. adapter فعلی ممکن است حساب‌های دارای وضعیت hedge یا پاسخ صفحه‌بندی ناقص را رد کند؛ این محدودیت نباید با نمایش پوزیشن خالی پنهان شود.

API `/api/me/execution-readiness` فقط وضعیت کاربر واردشده را گزارش می‌دهد و در پنل نمایش داده می‌شود. لایسنس معاملهٔ خودکار، اتصال TheTrueTrade Futures و بررسی خواندنی حساب در پنج دقیقهٔ اخیر جدا بررسی می‌شوند. حتی با تکمیل هر سه شرط، `trading_enabled=false` است: تطبیق هویت واقعی حساب با لایسنس، provisioning اجرای اختصاصی و چرخهٔ استاپ محافظ هنوز تکمیل نشده‌اند. این API کلید روشن‌کردن معامله نیست.

## آماده‌کردن بسته بدون دست‌زدن به سرور فعال

روی ماشین ساخت دارای منابع کافی، از ریشهٔ مخزن:

```bash
npm --prefix lbank_project/frontend ci
npm --prefix lbank_project/frontend run build
python3 lbank_project/tools/prepare_portal_release.py --output /tmp/trade-portal-preview.tar.gz
```

archive فقط ماژول‌های مشخص و خروجی فرانت را دارد. تنظیمات و دیتابیس تولید، `.env` و issuer key بسته‌بندی نمی‌شوند. فایل‌های ناشناخته و symlink در assets رد می‌شوند؛ manifest برای اعضای بسته SHA256 دارد. archive موجود بازنویسی نمی‌شود.

داخل archive، README فارسی مراحل ساخت image روی ماشین مناسب، انتقال image، ایجاد کلید تازهٔ preview، اتصال SSH به پورت loopback ۱۸۰۸۰ و توقف فقط preview را دارد. نام Compose جداست و پوشهٔ runtime جدا دارد. ساخت یا شروع آن روی سرور فعلی ۱ گیگ فعلاً انجام نشده است. frontend به Node روی سرور مقصد نیاز ندارد؛ backend همچنان به image و منابع اجرا نیاز دارد.

## ادامهٔ گام سوم بدون شروع سرویس جدید

ابزار `tools/ttt_contract_probe.py` فقط با کتابخانهٔ استاندارد Python کار می‌کند. آن را در SSH تعاملی اجرا کنید. کلید و secret را با ورودی مخفی همان ترمینال بدهید؛ هرگز در چت، خط فرمان یا فایل گزارش وارد نکنید.

```bash
python3 lbank_project/tools/ttt_contract_probe.py | tee /tmp/trade-ttt-contract.json
```

GETهای محدود: `/futures/assets`، `/futures/markets`، `/futures/positions?active=true` و `/futures/positions?page=1`. میزبان ثابت رسمی است، redirect پذیرفته نمی‌شود و endpoint سفارش در allowlist نیست. خروجی فقط شکل پاسخ، وجود فیلدهای مارجین، حداقل‌های بازار و تعداد رکوردهای استاپ را گزارش می‌کند؛ موجودی، قیمت شخصی، شناسهٔ حساب/پوزیشن، API key و secret چاپ نمی‌شوند. فقط صفحهٔ اول خوانده می‌شود و تکمیل صفحه‌بندی اثبات نمی‌شود.

اگر قبلاً کلیدها را در محیط همان process تنظیم کرده‌اید، گزینهٔ صریح `--from-env` وجود دارد. ابزار خودکار `.env` را باز نمی‌کند. نبود ترمینال تعاملی باعث توقف می‌شود تا getpass به ورودی قابل‌نمایش برنگردد.

این تست سفارش نمی‌سازد و حداقل موجودی لازم ندارد. وجود SL ذخیره‌شده روی پوزیشن قبلی، صحت استاپ ورود جدید را ثابت نمی‌کند. موفقیت GET نیز مجوز برداشت غیرفعال یا هویت حساب قابل تطبیق با لایسنس را اثبات نمی‌کند. نتیجه برای بررسی بعدی قرارداد API است، نه فعال‌سازی.

## اعتبارسنجی انجام‌شده

- ساخت Next.js، TypeScript و ۸ تست فرانت موفق.
- مجموعهٔ کامل pytest: ۶۸۷ موفق، ۲۱ skipped؛ سپس ۲ تست جدید probe و آزمون‌های release/preflight نیز پاس شدند.
- هر دو تم، ثبت‌نام، انتخاب پیش‌فرض TheTrueTrade Futures، فرم کلید و پیام آمادگی در Chromium بررسی شدند.
- تست امضای GET، جلوگیری از redirect/نوشتن، رمزگذاری و جداسازی مشتری، انقضای بررسی حساب و باقی‌ماندن ممنوعیت اجرا پاس شدند.
- archive در مسیر جدا باز و خود برنامه از همان بسته، بدون import از checkout، اجرا و تست شد.
- Compose بررسی شد و image واقعی Python 3.11 ساخته شد. در محیط ابری CA موقت با BuildKit secret برای pip استفاده شد؛ CA وارد image نشد.
- کانتینر آزمایشی با شبکهٔ `none` اجرا شد؛ health، چهار صفحهٔ عمومی، ثبت‌نام و readiness پاس شدند و کانتینر متوقف شد. محدودیت ۲۵۶ MiB در HostConfig ثبت شد ولی cgroup محیط توسعه ۳۲ GiB گزارش می‌کرد؛ بنابراین آزمون اجرای واقعی زیر سقف ۲۵۶ MiB یا تست ظرفیت محسوب نمی‌شود. RSS فرایند وب در یک نمونه حدود ۱۳۲ MiB بود.
- هیچ اتصال خصوصی واقعی به TheTrueTrade از این محیط تأیید نشده؛ گزارش سرور کاربر برای ادامه لازم است.
- deploy عمومی، تغییر سرویس‌های موجود، فعال‌سازی سفارش واقعی و تغییر قیمت فروش انجام نشده است.
