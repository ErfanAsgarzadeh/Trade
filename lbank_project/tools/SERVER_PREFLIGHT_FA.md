# بررسی یک‌مرحله‌ای سرور پیش از راه‌اندازی

از ریشهٔ مخزن اجرا کنید؛ نیازی به root، نصب بسته یا توقف سرویس‌ها ندارد:

```bash
python3 lbank_project/tools/server_preflight.py --repo . | tee /tmp/trade-preflight.json
```

اگر محیط مجازی پروژه فعال نیست، ابزار مسیرهای معمول `.venv` و `venv` را نیز برای وابستگی‌های آزمون بررسی می‌کند. وابستگی پیدا‌نشده در گزارش مشخص می‌شود؛ ابزار چیزی نصب نمی‌کند. اجرا معمولاً یک تا سه دقیقه زمان می‌برد و مهلت بخش pytest پنج دقیقه است.

گزارش JSON شامل نسخهٔ کد، منابع آزاد، Docker/Compose، Node و Python، همگام‌سازی ساعت، پورت‌های رایج، وجود خروجی فرانت، وضعیت مجاز و خلاصه‌شدهٔ تنظیمات پیش‌فرض اجرای زنده، وابستگی‌ها، تست‌های رگرسیون منتخب و اتصال عمومی HTTPS صرافی‌هاست. اتصال عمومی موفق به معنای مجازبودن حساب یا امکان معامله نیست. مسیرهای سفارشی runtime و تنظیمات داخل کانتینر مشتریان بررسی نمی‌شوند.

۲۰ فایل تست مربوط به احراز هویت، جداسازی مشتری، لایسنس، محصولات، صف صدور، کنترل ریسک، حساب مشترک، اجرای mirror، خطاهای سفارش، بررسی استاپ و فرانت اجرا می‌شوند. این‌ها تست‌های جداشده با adapterهای شبیه‌سازی‌شده هستند، نه آزمایش سفارش واقعی. محیط subprocess کلیدهای صرافی و مسیرهای تولید را به ارث نمی‌برد؛ دیتابیس و تنظیمات موقت دارد و plugin آزمون اتصال خارج از loopback را مسدود می‌کند. خروجی خام pytest، traceback، مسیر خصوصی، مشخصات حساب و مقادیر ناشناختهٔ تنظیمات در گزارش چاپ نمی‌شوند.

ابزار `.env`، فایل کلید حساب و کلید امضای لایسنس را باز نمی‌کند، سرویس یا معامله‌ای راه نمی‌اندازد، تنظیمات تولید را تغییر نمی‌دهد و هیچ سفارشی ارسال نمی‌کند. فقط فایل گزارش در صورت استفاده از `tee` و فایل‌های موقت تست ایجاد می‌شوند.

**خروجی `NOT_READY_FOR_CUSTOMER_LIVE_TRADING` در نسخهٔ فعلی انتظار می‌رود.** بخش اجرای زندهٔ پنل مشتری غیرفعال است. حتی با پاس‌شدن رگرسیون، مجوزهای API حساب، کارکرد واقعی استاپ، سفارش ناقص، بازیابی اتصال، بستن اضطراری، جریان انتها‌به‌انتهای هر مشتری، HTTPS دامنه، بکاپ و مانیتورینگ هنوز باید جداگانه تأیید شوند. این ابزار اجازهٔ معامله صادر نمی‌کند.

برای بررسی کوتاه بدون آزمون یا شبکه، گزینه‌های `--skip-tests` و `--skip-network` وجود دارند و در گزارش به‌وضوح NOT_RUN ثبت می‌شوند. نبود وابستگی، فایل آزمون یا checkout معتبر نیز گزارش می‌شود؛ نتیجهٔ اجرا‌نشده PASS اعلام نمی‌شود.

خروجی `/tmp/trade-preflight.json` را برای بررسی بعدی ارسال کنید. خطای قدیمی `tests/test_ui.cjs` در این مجموعه نیست؛ جزئیات آن در گزارش TITANIUM IRIS ثبت شده است.
