# فرانت Next.js پنل Trade

رابط مدیر در `/admin/` در دسترس کاربران با نقش admin است؛ [راهنمای فعال‌سازی مدیر و سرویس صدور](../ADMIN_WORKBENCH_FA.md).


صفحهٔ `/register/`، اشتراک «فقط سیگنال» و «معاملهٔ خودکار» اضافه شده‌اند. فروش هر دو تا تعیین قیمت نهایی بسته است؛ [راهنمای محصولات](../PRODUCTS_SIGNUP_FA.md).


فرانت با **Next.js 16 / React 19 / TypeScript / App Router** ساخته شده است.
کامپوننت‌های React مسئول ورود، انتخاب پلن، سفارش/تمدید/ارتقا، اتصال صرافی و نمایش
ربات‌ها هستند. API و منطق قیمت/صدور لایسنس در FastAPI پایتون باقی می‌مانند.
رابط فارسی، راست‌به‌چپ، واکنش‌گرا و قابل نصب به‌صورت PWA است.

## اجرای معمول: یک دامنه، یک سرویس

Node.js نسخهٔ ۲۲ یا بالاتر و Python مطابق فایل requirements لازم است. از این پوشه:

```bash
npm ci
npm run build
```

سپس از `lbank_project`، با تنظیمات و کاربران قبلی سرویس را اجرا کنید:

```bash
export PORTAL_KEY_FILE="$PWD/issuer-keys/portal.key"
export PORTAL_ORIGIN=http://127.0.0.1:8080
export PORTAL_ALLOW_LOCAL_HTTP=1
python portal_server.py
```

مرورگر: `http://127.0.0.1:8080`.
برای ساخت اولین کاربر، [راهنمای پنل](../PORTAL_FA.md) را ببینید؛ `init` برای
پایگاه دادهٔ موجود دوباره اجرا نمی‌شود.

`npm run build` خروجی واقعی Next.js را در `out/` می‌سازد؛ FastAPI همان خروجی و
فایل‌های `/_next/` را سرو می‌کند. در محیط تولید، اجرای Node جداگانه لازم نیست.
Dockerfile پنل بیلد چندمرحله‌ای دارد و این خروجی را خودکار می‌سازد.
اگر بیلد وجود نداشته باشد، صفحهٔ اصلی پاسخ ۵۰۳ با راهنمای بیلد می‌دهد؛ نسخهٔ قدیمی
HTML/JavaScript به‌جای Next.js نمایش داده نمی‌شود. API مستقل همچنان قابل استفاده است.

## توسعه با به‌روزرسانی سریع

بک‌اند را روی پورت ۸۰۸۰ اجرا کنید ولی مبدأ مرورگر را ۳۰۰۰ بگذارید:

```bash
# از lbank_project
export PORTAL_ORIGIN=http://127.0.0.1:3000
export PORTAL_ALLOW_LOCAL_HTTP=1
export PORTAL_KEY_FILE="$PWD/issuer-keys/portal.key"
python portal_server.py
```

در ترمینال دیگر از پوشهٔ frontend:

```bash
npm ci
npm run dev -- --hostname 127.0.0.1
```

مرورگر: `http://127.0.0.1:3000`. Next.js مسیرهای `/api/*` را به FastAPI روی
۸۰۸۰ می‌فرستد. از یک hostname ثابت استفاده کنید؛ localhost و 127.0.0.1 را مخلوط
نکنید. مبدأ بالادستی دلخواه از مرورگر دریافت نمی‌شود. تنظیم مبدأ برای استقرار
HTTPS باید دقیقاً با آدرس نهایی یکی باشد.

## نشست، CSP و حریم خصوصی

- نشست در کوکی HttpOnly بک‌اند است و در localStorage ذخیره نمی‌شود.
- درخواست‌های تغییردهندهٔ داده، CSRF دریافت‌شده از `/api/me` را ارسال می‌کنند.
- هنگام خروج یا پایان نشست، درخواست‌های در حال اجرا لغو و پاسخ‌های قدیمی رد می‌شوند؛
  کامپوننت‌های خصوصی از صفحه حذف می‌شوند.
- Next.js برای راه‌اندازی React چند اسکریپت درون HTML تولید می‌کند. سرویس فقط
  هش SHA-256 همان اسکریپت‌های خروجی را در CSP مجاز می‌کند؛ `unsafe-inline` و
  `unsafe-eval` برای نسخهٔ تولیدی اضافه نشده‌اند.
- Service Worker فقط صفحهٔ عمومی قطع اتصال را ذخیره می‌کند؛ API، دادهٔ حساب،
  لایسنس و HTML دارای نشست به Cache Storage وارد نمی‌شوند.
- فونت و آیکون‌ها محلی‌اند و CDN یا کلید صرافی برای بیلد لازم نیست.

## تست

```bash
npm run typecheck
npm test
npm run build
```

از پوشهٔ lbank_project، تست مرورگر تولیدی و API:

```bash
PYTHONPATH=. python -m pytest tests/test_portal_browser.py tests/test_portal.py -q
```

تست مرورگر به Playwright و Chromium نیاز دارد؛ دستور نصب در
[راهنمای لایسنس](../CAPITAL_LICENSE_FA.md) است. این تست نسخهٔ بیلدشده را با بک‌اند
واقعی و پایگاه دادهٔ موقت اجرا می‌کند: ورود، خروج، خرید/لغو/ارتقا، دانلود لایسنس،
پاک‌شدن کلیدهای فرم، نمایش موبایل و حالت آفلاین بررسی می‌شوند.

تعرفه‌ها و محدودیت‌های اجرایی در [CAPITAL_LICENSE_FA.md](../CAPITAL_LICENSE_FA.md)
توضیح داده شده‌اند. اتصال درگاه پرداخت و تأیید انتقال‌ها هنوز دستی است؛ مهاجرت
فرانت اجرای واقعی معاملات را فعال نمی‌کند.
