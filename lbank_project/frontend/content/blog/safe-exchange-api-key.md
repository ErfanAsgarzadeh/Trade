برای اینکه یک ربات ترید بتواند در حساب صرافی شما معامله کند، به **کلید API** نیاز دارد. کلید API مثل یک کارت دسترسی است: صرافی به هر کسی که آن را داشته باشد، همان اجازه‌هایی را می‌دهد که هنگام ساخت کلید انتخاب کرده‌اید. پس امنیت حساب شما بیشتر از هر چیز به این بستگی دارد که این کارت چه درهایی را باز می‌کند.

## کلید API از چه بخش‌هایی تشکیل شده؟

بیشتر صرافی‌ها دو رشته به شما می‌دهند:

- **API Key:** شناسهٔ عمومی کلید.
- **Secret Key:** رمز محرمانه‌ای که درخواست‌ها با آن امضا می‌شوند. این رشته معمولاً فقط یک بار نمایش داده می‌شود.

هر کسی که این دو را داشته باشد، می‌تواند به‌جای شما با صرافی صحبت کند؛ در حدود دسترسی‌هایی که برای کلید فعال کرده‌اید.

## چه دسترسی‌هایی لازم است و چه دسترسی‌هایی نه؟

یک ربات معامله‌گر فقط به این دسترسی‌ها نیاز دارد:

- **خواندن اطلاعات حساب:** موجودی، پوزیشن‌ها و سفارش‌های باز.
- **معامله:** باز و بسته کردن پوزیشن و ثبت سفارش‌های حد ضرر.

و هرگز به این دسترسی نیاز ندارد:

- **برداشت (Withdraw):** هیچ ربات تریدی برای معامله به برداشت نیاز ندارد. کلیدی که دسترسی برداشت ندارد، حتی اگر لو برود، نمی‌تواند پول را از حساب شما خارج کند.
- **انتقال بین حساب‌ها یا ساخت زیرحساب:** این‌ها هم برای معامله لازم نیستند.

اگر سرویسی از شما کلید با دسترسی برداشت خواست، یا خواست پول را به حساب خودش واریز کنید، این یک علامت هشدار جدی است.

## محدودیت IP؛ لایهٔ دوم امنیت

بیشتر صرافی‌ها اجازه می‌دهند کلید فقط از آدرس‌های IP مشخصی قابل استفاده باشد. اگر ربات روی سروری با IP ثابت اجرا می‌شود، کلید را به همان IP محدود کنید. در این حالت حتی اگر کلید و رمز آن لو برود، از هیچ جای دیگری کار نمی‌کند.

## نکته‌های نگهداری کلید

1. **برای هر سرویس، کلید جداگانه بسازید.** اگر یک سرویس را کنار گذاشتید، فقط کلید همان را حذف می‌کنید.
2. **کلید را در پیام‌رسان، ایمیل یا اسکرین‌شات نفرستید.** فقط در فرم امن خود سرویس وارد کنید.
3. **Secret Key را جایی ذخیره نکنید که دیگران به آن دسترسی دارند.** اگر لازم نیست، اصلاً ذخیره نکنید؛ همیشه می‌توان کلید تازه ساخت.
4. **احراز هویت دومرحله‌ای (2FA) را روی حساب صرافی فعال کنید.** ساخت و حذف کلید باید به تأیید دومرحله‌ای نیاز داشته باشد.
5. **کلیدهای قدیمی را مرتب حذف کنید.**

## اگر فکر می‌کنید کلید لو رفته

- فوراً از پنل صرافی کلید را حذف یا غیرفعال کنید.
- پوزیشن‌ها و سفارش‌های باز را بررسی کنید.
- رمز حساب صرافی را عوض کنید و دستگاه‌های واردشده را بررسی کنید.
- کلید جدید با دسترسی محدود و محدودیت IP بسازید.

## آوینا با کلید API چه می‌کند؟

آوینا مدل **بدون نگهداری سرمایه (Non-custodial)** دارد: هیچ واریزی به آوینا لازم نیست و سرمایه همیشه در حساب صرافی خودتان می‌ماند. کلید API باید بدون دسترسی برداشت ساخته شود و آوینا فقط برای خواندن حساب، باز و بسته کردن پوزیشن و ثبت حد ضرر از آن استفاده می‌کند. کلید پس از ثبت به‌صورت رمزنگاری‌شده نگهداری می‌شود.

## جمع‌بندی

کلید API امن یعنی کمترین دسترسی لازم: خواندن و معامله، بدون برداشت، و در صورت امکان محدود به یک IP. با این تنظیمات، بدترین اتفاق ممکن به‌جای از دست رفتن سرمایه، معاملات ناخواسته است که با حذف کلید فوراً متوقف می‌شود. برای قدم بعدی، مقالهٔ [حد ضرر در معاملات فیوچرز](/blog/futures-stop-loss/) را بخوانید.
