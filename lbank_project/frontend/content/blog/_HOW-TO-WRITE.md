# نوشتن مقالهٔ تازه برای بلاگ آوینا

هر فایل `.md` در این پوشه یک مقاله است. فایل‌هایی که نامشان با `_` شروع شود (مثل همین فایل) منتشر نمی‌شوند؛ برای پیش‌نویس از همین قاعده استفاده کنید.

1. نام فایل آدرس مقاله می‌شود و فقط حروف کوچک لاتین، عدد و خط تیره دارد؛ مثلاً `bitcoin-halving.md` در آدرس `/blog/bitcoin-halving/` منتشر می‌شود.
2. فایل با این سربرگ شروع می‌شود:

```
---
title: عنوان مقاله (حدود ۵۰ تا ۶۰ حرف، با عبارت کلیدی اصلی)
description: خلاصهٔ یک‌جمله‌ای برای نتایج گوگل (حدود ۱۲۰ تا ۱۶۰ حرف)
date: 2026-11-20
updated: 2026-11-25
keywords: عبارت اول, عبارت دوم
---
```

   `updated` اختیاری است؛ فقط وقتی مقاله را واقعاً بازنویسی کردید آن را بگذارید.
3. متن با این قالب‌ها نوشته می‌شود: `## تیتر`، `### زیرتیتر`، `- فهرست`، `1. فهرست شماره‌دار`، `**پررنگ**`، `[متن پیوند](/blog/futures-stop-loss/)` و `> نقل قول`. HTML پذیرفته نمی‌شود.
4. اگر مقاله سه تیتر `##` یا بیشتر داشته باشد، فهرست مطالب خودکار ساخته می‌شود.
5. بعد از اضافه کردن فایل، سایت را دوباره بسازید (`docker compose ... up -d --build`). نقشهٔ سایت (sitemap) خودکار به‌روز می‌شود.

برای سئو: در هر مقاله به یکی دو مقالهٔ دیگر و به صفحهٔ اصلی پیوند بدهید، و هیچ‌وقت سود تضمینی وعده ندهید.
