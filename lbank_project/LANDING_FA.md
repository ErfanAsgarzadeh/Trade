# صفحهٔ معرفی عمومی و هیروی بک‌تست

صفحهٔ `/` اکنون صفحهٔ معرفی محصول است؛ ورود و پنل مشتری در **`/dashboard/`**،
ثبت‌نام در `/register/` و کارتابل مدیر در `/admin/` قرار دارند. ساخت این صفحه به
معنی اتصال دامنه یا انتشار عمومی نیست؛ در این جلسه دامنه‌ای تنظیم نشده است.
دستورهای بیلد و استقرار معمول پنل، همین صفحه را نیز همراه Next.js می‌سازند.

هیرو دارای بازپخش ده‌ثانیه‌ای منحنی واقعی خروجی روزانه، نشانگر تاریخ و ارزش حساب،
نشان سه ربات، عدد پایان دوره و بیشترین افت سرمایه است. توقف، ادامه و بازپخش با
دکمه انجام می‌شود. هنگام مخفی‌شدن تب، حرکت متوقف می‌شود. `prefers-reduced-motion`
رعایت می‌شود و بدون درخواست کاربر انیمیشن آغاز نمی‌شود. نمایش اولیهٔ بدون JS
نیز نمودار کامل و نتیجهٔ ثابت را نشان می‌دهد؛ موشن شرط دسترسی به اطلاعات نیست.

## اعداد تبلیغ

برای ادعای «پنج‌ساله»، فقط بازهٔ کامل **۱ ژانویهٔ ۲۰۲۱ تا پایان ۲۰۲۵ UTC** از
خروجی یخ‌زدهٔ قبلی انتخاب شده است؛ دادهٔ ۲۰۲۶ وارد این ادعا نشده است:

- سرمایهٔ آغاز: ۱۰٬۰۰۰ دلار
- ارزش پایان شبیه‌سازی: ۹۶۴٬۴۵۱٫۷۷ دلار
- بازده کل: حدود ۹۵۴۴٫۵۲٪
- بیشترین افت سرمایهٔ پایان دقیقه: حدود ۳۰٫۷۰٪
- سناریو: هر سه ربات، بدون F، بدون برداشت و با سرمایه‌گذاری مجدد سود

این نتیجه با سناریوی برداشت ۵۰٪ سود و خرید طلا متفاوت است. منحنی هیرو ارزش
پایان روز را روی محور لگاریتمی نشان می‌دهد؛ DD از بدترین مقدار دقیقه‌ای روزها
خوانده می‌شود، نه افت محاسبه‌شده از چند نقطهٔ انیمیشن. مقیاس و تعریف‌ها در صفحه
آمده‌اند. رشد بزرگ مدل و ریسک، کنار هم نشان داده شده‌اند. نتیجهٔ حساب زنده،
ممیزی مستقل یا تضمین بازده آینده ادعا نشده است.

دادهٔ CSV روزانه، JSON خلاصه و روش محاسبه از بخش نتایج قابل دانلود هستند:
`frontend/public/backtest/`. این بسته فقط خروجی پژوهشی دارد؛ هیچ حساب یا
اطلاعات خصوصی مشتری در آن وجود ندارد. همین JSON منبع اعداد و منحنی کامپوننت‌هاست.

اسکریپت بازتولید تجمیع:

```bash
python frontend/tools/build_public_backtest.py
```

اسکریپت فقط ورودی بازبینی‌شده با SHA-256 شناخته‌شده را می‌پذیرد. این دستور
تجمیع و تولید خروجی عمومی را تکرار می‌کند، نه اجرای کامل بک‌تست دقیقه‌ای روی
آرشیو بازار. برای تغییر دوره یا نتیجه، ورودی و متن روش باید دوباره بررسی شوند؛
اعداد هیرو نباید دستی و جدا از منبع تغییر کنند.

فروش محصولات از `/api/plans` خوانده می‌شود تا با تغییر وضعیت واقعی در کارتابل
مدیر ناسازگار نشود. هیچ قیمت یا فروش جدیدی با اضافه‌شدن صفحه باز نشده است.
اشتراک autotrade همچنان به‌روشنی موتور فعلی paper را معرفی می‌کند.

## اجرا و بررسی

از پوشهٔ `lbank_project`:

```bash
npm --prefix frontend ci
npm --prefix frontend run build
python portal_server.py
```

برای اجرای اولیه، همان PORTAL_KEY_FILE، پایگاه داده و تنظیم مبدأ را طبق
[PORTAL_FA.md](PORTAL_FA.md) تنظیم کنید. در حالت محلی، صفحهٔ معرفی در
`http://127.0.0.1:8080/` و پنل در `http://127.0.0.1:8080/dashboard/` است.

آزمون‌های اعداد و مرورگر:

```bash
PYTHONPATH=. python -m pytest tests/test_public_backtest.py tests/test_landing_browser.py -q
```

تست مرورگر، نمایش در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل، توقف/ادامه، تنظیم کاهش
حرکت، لینک‌های ورود/ثبت‌نام، دسترسی به داده و نبود خطای CSP یا hydration را
بررسی می‌کند. زیرساخت انتشار عمومی یا خرید دامنه در این تغییر ایجاد نشده است.
