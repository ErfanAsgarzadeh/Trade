# ماتریس High-CAGR Donchian

۳۸۴ ترکیب از پیش اعلام‌شده، ۱٬۱۵۲ اجرای مستقل Full/Train/2025–2026.
بازه همان 2021-10-05 تا 2026-10-05 (انتهای غیرشامل) است. تمام پنج نماد
۲٬۶۲۹٬۴۴۰ دقیقهٔ واقعی با هش یکسان به اجرای قبلی دارند. اندیکاتورهای دو
پریست در ۱H و ۴H با پنجرهٔ دقیق ۱۹۹ کندل بسته و ۱۲۰ کنترل برابری ساخته شدند.

دو سبد FIVE و ALTS، ورودهای ۴H N10/N15 و ۱H N20/N40، دو پریست، دو
تریل استاپ Donchian10/Kijun، با/بدون افزودن، ریسک‌های ۰٫۷۵/۱/۱٫۲۵٪ و
چهار/پنج اسلات بررسی شدند. هیچ ریسک پایین‌تر یا شرط شل‌شده‌ای پس از مشاهده
نتیجه اضافه نشد. شکست ۱H تحت فقط Kumo بستهٔ ۴H است، بدون الزام شکست Donchian
۴H. تریل هر گزینه روی تایم‌فریم ورود است. کیجونِ کلوزمحور قبلی کنترل جداست.

برندهٔ سقف ۳۵٪: FIVE/standard/4h/N10/DONCHIAN10/PY1/R0.0075/P4.
CAGR ۳۲٫۲۳۵٪، سود خالص $۳۰٬۴۲۵٫۰۱، DD ۳۴٫۵۶۳٪؛ ۱۵۸۲ ورود پایه و
۱۸۱ واحد افزودن. CAGR Train=32.973% و اعتبارسنجی 2025–2026=31.578%.
زیر سقف ۳۰٪، بهترین CAGR=26.019% و DD=27.592% است. زیر ۲۵٪ هیچ
برنده‌ای وجود ندارد. بیشترین CAGR بدون سقف DD=53.157% با بدترین DD=49.919%.
هدف ۵۰–۱۰۰٪ با افت مجاز ۳۵٪ محقق نشد.

افزودن تنها یک واحد، با نصف ریسک، پس از ۲R و استاپ سودده پوشش‌دهندهٔ هزینه،
روی شکست بعدی و با همان استاپ است. REJECT 1.2% برای واحد افزوده هم اعمال
می‌شود. اسلات نمادی است. بودجهٔ مارجین کل ۶۰٪ با اهرم معادل پنج و سقف هر
واحد برابر 60%/slots*5 است. افزودن هم از بودجهٔ آزاد کل مصرف می‌کند. اندازه
بر اساس ریسک، فاصلهٔ استاپ و ۰٫۱۲٪ fee + ۰٫۰۴٪ ذخیره لغزش ساخته می‌شود.

هزینه واقعی: fee رفت‌وبرگشت ۰٫۱۲٪، لغزش ۲bps هر fill، Funding مشاهده‌شده
Binance تا سپتامبر ۲۰۲۶، Funding نامعلوم ۱–۴ اکتبر با هزینهٔ adverse 0.01%
در هر ۸ ساعت. ذخیرهٔ لغزش اندازه‌گیری ریسک دوباره از موجودی کسر نمی‌شود.
کنترل‌های موتور قبلی از اندازه‌گیری قدیمی و سقف ۱۰۰٪ مارجین/۱۲۵٪ نُوشنال
هر واحد استفاده می‌کنند؛ هزینه‌های واقعی یکسان‌اند.

همهٔ ۱٬۱۵۲ دفتر با net=gross-fee+funding، سقف ریسک و مارجین و قواعد
افزودن تطبیق شدند. replay و مسیر معکوس دقیقه، نتیجهٔ برنده را تغییر ندادند؛
دو برابر هزینهٔ Funding نامعلوم، CAGR را به ۳۲٫۲۲۷٪ رساند. ۱۶۸ تست پایتون
و تست DOM داشبورد پاس شدند. گزارش نمایش و فیلتر داده‌ها نیز بررسی شده است.

## ادامه و بازتولید

```bash
python high_cagr/restore_inputs.py
python high_cagr/prepare.py
python high_cagr/run_suite.py --workers 4
python high_cagr/controls.py
python high_cagr/verify_results.py
python high_cagr/make_report.py
```

وابستگی‌ها همان requirements پروژه/portfolio هستند. `restore_inputs.py`
از قطعات دادهٔ موجود در commit ثابت بازیابی و SHA-256 را کنترل می‌کند؛
Binance دوباره دانلود نمی‌شود. هر نتیجهٔ دوره‌ای اتمیک و قابل ادامه است.
`matrix.json` همهٔ نتیجه‌ها را در خود دارد و آمار تاریخی دیگر دست‌نخورده‌اند.
همهٔ NPZهای ممیزی‌شده به‌صورت ۵۹ قطعهٔ ZIP_STORED در data_parts ذخیره‌اند:

```bash
python high_cagr/restore_ledgers.py
```

BNB پس از مشاهدهٔ نتایج حذف شده و خود جست‌وجو نیز اطلاعات ۲۰۲۵–۲۰۲۶ را
مصرف می‌کند؛ این دوره اعتبارسنجی مشاهده‌شده است، نه OOS دست‌نخورده.
OHLC یک‌دقیقه‌ای جایگزین دادهٔ tick/mark-price نیست؛ لیکوئیدیشن و سطوح
تاریخی maintenance margin بازسازی نشده‌اند. نتایج، تضمین رشد آینده نیستند.
ربات فعلی paper-only است و نتیجهٔ اجرای دقیقه‌ای به معنای اتصال زندهٔ LBank نیست.
