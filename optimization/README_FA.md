# اجرای مجدد بهینه‌سازی بیت‌کوین

دوره: 2021-10-05 تا ابتدای 2026-10-05 UTC. داده دقیقه‌ای قرارداد دائمی BTCUSDT بایننس؛ سرمایه اولیه هر اجرای مستقل 10,000 دلار.

432 ترکیب غیرتکراری × سه دوره (کل، آموزش، دوره بعدی). 15 تعریف خروج، MTF/SINGLE، حداقل استاپ غیرفعال/بازکردن/ردکردن و شش حالت شیب/ADX؛ ترکیب‌های تریل یکسان در SINGLE حذف شده‌اند. رتبه‌بندی بر اساس بیشترین سود خالص کل دوره و سپس PF است. تعداد کم معامله از رتبه‌بندی حذف نشده و صریحاً در گزارش اعلام شده است.

برنده: `SINGLE__B_runner_hard4__reject__slope_ADX25`؛ 8 معامله، سود خالص $125.207072 و PF=1.508030. این تنظیم با دو سیاست دیگر حداقل استاپ هم‌نتیجه بود؛ REJECT در config فعال شده است. خروج جزئی صفر؛ سربه‌سر در 2R؛ هدف سخت 4R؛ تریل 4h Kijun با 0.5ATR؛ ADX(14)≥25 و شرط شیب فعال. فقط BTC در config فعال است، چون سایر نمادها در این آزمون بهینه نشده‌اند. این انتخاب با مشاهده کل دوره است و دوره بعدی یک آزمون مستقل دست‌نخورده نیست.

## اجرا

از ریشه بسته:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r optimization/requirements.txt
python optimization/run_suite.py
python optimization/verify_results.py
python optimization/make_report.py
python -m pytest lbank_project/tests btc_backtest/test_backtest.py -q
node lbank_project/tests/test_ui.cjs
```

`features.npz` داده دقیقه‌ای و ویژگی‌های بسته‌شده همین آرشیوها را نگه می‌دارد و امکان تکرار آفلاین را می‌دهد. برای بازسازی از آرشیو خام، داده بسته `btc_five_year_source_data.zip` را به `btc_backtest/cache/` استخراج کنید، features.npz را کنار بگذارید و run_suite.py را اجرا کنید. فایل data_manifest.json شامل SHA-256 هر آرشیو است. فایل features_manifest.json هش داده ویژگی‌ها و صورت وضعیت منبع را ثبت می‌کند.

`baseline/` شامل config و موتور پیش از اصلاح است؛ تغییر config جدید مبنای مقایسه را تغییر نمی‌دهد. `kernel.py` موتور دقیقه‌ای JIT است؛ تطبیق کامل تعداد، سود و DD مبنا با اجرای قبلی در run_suite اجباری است. `verify_results.py` مبنا و برنده را دوباره اجرا و ترتیب High/Low را معکوس می‌کند و 24 پنجره ADX واقعی را با کد ربات تطبیق می‌دهد.

`output/matrix.json` پارامترهای عددی و تمام نتایج را دارد. ترتیب params:
`[tp_rr, partial_pct, exit_kind, trail_ATR, trail_minutes, hard_TP_R, minimum_stop_fraction, stop_policy]`.
exit_kind: 0=legacy، 1=A-quarter، 2=A-close-confirm، 3=B-milestone، 4=pure-Kijun. stop_policy: 0=none، 1=widen، 2=reject. در همه حالت‌ها، شکست بسته‌شده Kijun خروج کامل است؛ بافر ATR مربوط به استاپ تریل است.

هزینه مشترک: 0.12% رفت‌وبرگشت، 2bps لغزش نامطلوب هر fill، Funding واقعی بایننس؛ برای مواجهه فعال در چهار روز اکتبر فاقد Funding آرشیوی، 0.01% هزینه فرضی نامطلوب هر هشت ساعت. برنده و مبنا هیچ مواجهه با این فرض ندارند. خطر گپ و مسیر دقیق tick از OHLC دقیقه‌ای کاملاً قابل بازسازی نیست. کاهش محاسبات با پرش از دقیقه‌های بدون پوزیشن به سیگنال بعدی انجام می‌شود؛ زمان نگهداری معامله دقیقه به دقیقه پردازش می‌شود.

موتور ربات فعلی کاغذی است و PnL نمایشی آن مثل نسخه قبلی فقط کارمزد دارد؛ Funding تاریخی و لغزش در موتور بک‌تست اعمال می‌شوند. نتایج بایننس هزینه‌ها یا قابلیت اجرای LBank را اثبات نمی‌کند. تغییر config جدید به پوزیشن باز قدیمی تحمیل نمی‌شود: ستون‌های جدید SQLite مهاجرت می‌کنند و تنظیم خروج هر پوزیشن حفظ می‌شود.
