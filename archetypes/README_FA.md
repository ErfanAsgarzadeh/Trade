# بنچمارک چهار خانوادهٔ تمیز بیت‌کوین

داده و هزینه‌ها همان مرحله قبل هستند: BTCUSDT دائمی بایننس، کندل یک‌دقیقه‌ای 2021-10-05 تا ابتدای 2026-10-05 UTC، سرمایه اولیه 10,000 دلار. 112 تعریف از چهار خانواده در کل دوره، آموزش 2021–2024 و دوره بعدی 2025–2026 اجرا شده‌اند. شبکه قبل از اجرا در predeclared_grid.json ثبت شده؛ اصلاح‌های بعدی صرفاً کنترل سازگاری اجرای pending/market و حداقل استاپ در قیمت واقعی fill بوده‌اند، بدون تغییر شبکه پارامترها.

شرط پذیرش: حداقل 40 معامله در کل پنج سال، سود خالص مثبت آموزش، سود خالص مثبت دوره بعدی. بین واجدشرایط‌ها بیشترین سود خالص کل دوره و سپس PF انتخاب می‌شود. 17 ترکیب قبول شدند. بهترین PF جداگانه در selection.json ثبت شده است.

برنده: `DONCHIAN__SINGLE__standard__MARKET__STOP_TRAIL__KIJUN__DONCHIAN10__N20`؛ 288 معامله، 157 خرید و 131 فروش، خالص $2,984.14، PF=1.3803 و Max DD=7.0968%. آموزش $2,773.88؛ دوره بعدی $163.82. دوره بعدی در انتخاب دخالت دارد و داده مستقلِ دست‌نخورده نیست. هیچ پیکربندی واجدشرایط با 40–60 معامله پیدا نشد؛ هدف 25–60 معامله پنج‌ساله محقق نشد.

## اجرا از ریشه بسته

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r archetypes/requirements.txt
python archetypes/run_suite.py
python archetypes/verify_results.py
python archetypes/make_report.py
python archetypes/check_report.py
python -m pytest lbank_project/tests btc_backtest/test_backtest.py -q
node lbank_project/tests/test_ui.cjs
python archetypes/deploy_winner.py
```

strategy_archetypes.py باید کنار lbank_bot.py باشد؛ تعریف‌های ورود/رژیم/اندیکاتور مشترک‌اند. برای اجرای خود ربات و داشبورد، راهنمای lbank_project/README_FA.md را بخوانید. حالت paper حفظ شده و هیچ سفارش زنده ثبت نشده است.

features.npz در optimization/ همان داده و ویژگی‌های آماده مرحله قبلی است و SHA-256 آن قبل از هر اجرا کنترل می‌شود. محاسبات EMA برای هر پنجره 199 کندل و seed SMA انجام می‌شوند؛ تنظیمات دوگانه ایچیموکو از همان OHLC بازسازی می‌شوند. فایل data_manifest.json صورت وضعیت 126 آرشیو اصلی را دارد. داده خام را می‌توان از بسته قبلی btc_five_year_source_data.zip بازیابی کرد؛ raw/cache در این بسته تکرار نشده‌اند.

چهار خانواده و تمام جزئیات اجرایی در report_fa.html آمده‌اند. در خانواده 4، سیگنال و استاپ اولیه همیشه 4h و مقایسه MTF مربوط به تریل 1h است. در خانواده‌های 1–3، MTF رژیم 4h و ورود/تریل 1h دارد. سفارش شکست GTC است: با برخورد به استاپ سیگنال، نامعتبر شدن رژیم، توقف ورود یا پایان دوره لغو می‌شود. ورود بازار پس از بسته‌شدن کندل در Open اولین دقیقه بعد با برچسب +3s است؛ از قیمت Close آینده استفاده نمی‌شود. کانال ورود از کندل‌های قبلی و کانال تریل از کندل‌های بسته اخیر است. H2/L2 یک تعریف مکانیکیِ قابل بازتولید است و تحلیل اختیاری آل بروکس را بازسازی نمی‌کند.

ریسک 0.5%، سقف نُوشنال 50%، کارمزد 0.12% رفت‌وبرگشت، لغزش 2bps هر fill و Funding بایننس حفظ شده‌اند. استاپ کمتر از 1.2% در سیگنال و قیمت واقعی ورود رد می‌شود. Funding واقعی تا سپتامبر 2026 موجود است؛ آرشیو چهار روز اکتبر موجود نبود، پس همان هزینه فرضی نامطلوب 0.01% نُوشنال هر 8 ساعت اعمال شد. برنده فقط یک رویداد، $0.37275، دارد؛ با دو برابر کردن آن سود $2,983.76643 شد. این قسمت Funding واقعی نیست. PnL نمایشی ربات paper فقط کارمزد دارد؛ Funding و لغزش در موتور بک‌تست اعمال می‌شوند.

مقایسه زمانی هر بخش از سرمایه 10,000 و بدون پوزیشن شروع می‌شود و پوزیشن باز انتهای بخش بسته می‌شود؛ مجموع دو بخش با اجرای پیوسته الزاماً برابر نیست. PF و میانگین برد/باخت از سود خالصِ ورود تا خروج کامل محاسبه می‌شوند. مسیر داخل دقیقه OHLC فرضی است؛ تحلیل حساسیت با مسیر معکوس هم اجرا شده است.

`prior/` کد و config مرحله قبل را نگه می‌دارد؛ خروجی‌های مرحله قبل در optimization/output و btc_backtest/output باقی می‌مانند. فایل report_fa.html مشترک به گزارش جدید جایگزین شده است. برای دوره‌ها، هزینه‌ها، محدودیت‌ها، تمامی 112 پیکربندی و دفتر 288 معامله، گزارش و JSONهای output/ را ببینید.
