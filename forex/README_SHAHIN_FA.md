# شاهین فارکس — پژوهش و بهینه‌سازی پنج‌ساله

این مسیر در برنچ `feature/forex-5y-majors` مستقل از پیکربندی live/paper کریپتو طراحی شده است و **هیچ تنظیماتی را روی شاهین اصلی یا main اعمال نمی‌کند**.

## تهیهٔ داده و اجرا

پیش‌نیاز: Python 3.11+، `numpy`، `pandas`، Node.js/npm.

از ریشهٔ پروژه:

```bash
python -m pip install numpy pandas
python forex/download_forex.py --side bid
python forex/download_forex.py --side ask
python -m unittest discover -s forex -p "test_*.py" -v
python forex/optimize_shahin.py
```

ابتدا بررسی کنید هر دو فایل `forex/data/manifest_bid.json` و `manifest_ask.json` و هر شش CSV دقیقه‌ای برای EURUSD/GBPUSD/USDJPY موجودند. optimizer برای فایل‌های ناقص یا checksum نامعتبر خطا می‌دهد؛ دادهٔ مصنوعی جایگزین نمی‌شود.

گزارش: `forex/data/reports/shahin_forex_5y.json` (در Git ثبت نمی‌شود). گزارش شامل شواهد SHA256 داده، نتایج train/validation/test هر جفت‌ارز، پارامتر انتخابی و فرض‌های هزینه است. **تا دریافت دیتای واقعی و اجرای برنامه، هیچ نتیجهٔ بک‌تستی گزارش نشده است.**

هزینه‌ها را مطابق کارگزار هدف تغییر دهید:

```bash
python forex/optimize_shahin.py \
  --risk-pct 0.0075 --leverage 5 --margin-cap 0.8 \
  --commission-rt-per-100k 7 --slippage-bps 0.5 --lot-units 1000
```

کمیسیون نمونه ۷ دلار برای هر ۱۰۰هزار واحد ارزش اسمی دلاری به‌صورت **رفت‌وبرگشت** فرض شده، نه هزینهٔ قطعی یک کارگزار. اسپرد از اختلاف Bid/Ask فید اندازه‌گیری می‌شود؛ لغزش adverse جداگانه اعمال می‌شود. Swap/rollover و هزینهٔ تأمین مالی در این نسخه محاسبه نشده‌اند.

## طراحی آزمون (بدون نشت داده)

| بخش | بازه (UTC؛ انتها غیرشامل) | کاربرد |
|---|---|---|
| Train | 2021-11-12 تا 2025-01-01 | رتبه‌بندی همه ۴۸ ترکیب |
| Validation | 2025-01-01 تا 2026-01-01 | انتخاب نهایی از ۸ گزینهٔ برتر |
| Final test | 2026-01-01 تا 2026-11-12 | فقط یک اجرای مستقل از گزینهٔ منجمد |

۴۸ تنظیم از حاصل‌ضرب دو پریست ایچیموکو (standard/crypto)، Donchian10/20، ضریب ATR برابر ۱٫۵/۲/۲٫۵، حداقل استاپ ۸/۱۵ پیپ و فعال/غیرفعال بودن فیلتر میانهٔ ATR60 ساخته می‌شوند. معیار امتیازدهی: میانگین بازده سه نماد منهای جریمهٔ میانگین افت سرمایهٔ روزانه و پراکندگی بازده. سرمایهٔ مستقل ۱۰٬۰۰۰ دلار برای **هر جفت‌ارز** فرض شده است؛ این مطالعه بازده/افت سبد با سرمایه مشترک را ادعا نمی‌کند.

## مرزهای مدل

- هستهٔ سیگنال شاهین: شکست Donchian در کندل بستهٔ ۴ساعته، تأیید قرارگیری قیمت در بیرون ابر Kumo شیفت‌شده و استاپ ATR، همراه تریل Donchian10 و قفل سود ۱R→۰٫۱R. تنها کندل‌های ۴ساعتهٔ کامل استفاده می‌شوند.
- ورود در **باز شدن دقیقهٔ بعد از بسته‌شدن کندل**؛ خرید در Ask و فروش در Bid. خروج از پوزیشن لانگ در Bid و شورت در Ask است. استاپ در گپ نامطلوب با قیمت بازشدن دقیقه اجرا می‌شود.
- USDJPY: سود و زیان ین با قیمت Ask زمان خروج به دلار تبدیل می‌شود. سایز بر اساس ریسک دلاری و سقف مارجین و حداقل ۱۰۰۰ واحد پایه گرد می‌شود.
- گپ‌های آخر هفته پر نمی‌شوند. سیگنال فقط وقتی یک دقیقه دقیقاً در مرز بسته‌شدن ۴ساعته موجود باشد اجرا می‌شود؛ سیگنال از دست‌رفته به جلسهٔ بعد موکول نمی‌شود. حرکت درون دقیقه و تقدم برخورد به چند سطح با tick بازسازی نمی‌شود.
- این **پورت پژوهشی هستهٔ شاهین** است، نه شبیه‌سازی بیت‌به‌بیت همهٔ قابلیت‌های نسخهٔ کریپتو. Pyramid، تأمین مالی و Swap، حد ضرر ناشی از مارجین، محاسبهٔ Mark-to-Market پیوسته، قوانین خاص صرافی، توقف زیان ۲۴ساعته و فیلترهای افزودهٔ خاص نسخهٔ استقرار اجرا نمی‌شوند. افت سرمایه بر مبنای نمونه‌برداری روزانه است، نه DD دقیقه‌ای.
- هر دورهٔ train، validation و test با سرمایهٔ ۱۰هزار دلار **مستقل reset** می‌شود؛ نتایج دوره‌ها را نباید با بازده پیوستهٔ یک حساب پنج‌ساله اشتباه گرفت.
- Volume فید Dukascopy حجم معاملهٔ تجمیعی فارکس نیست و در انتخاب پارامتر استفاده نشده است.
- **محدودیت حیاتی:** راه‌انداز دانلود قبلی نیاز به تأیید تجربی سازگاری با نسخهٔ CLI نصب‌شده و پوشش واقعی داده دارد؛ تا قبل از اعتبارسنجی دانلود/تست‌ها، اجرای موفق این workflow تأیید نشده است. همچنین خروجی حاصل پیش‌بینی عملکرد آینده نیست.

این برنچ صرفاً پژوهش و بک‌تست است. هرگونه تغییر پیکربندیِ شاهین عملیاتی مستلزم بررسی جداگانه، تست اجرای paper و کنترل‌های ریسک متناسب با بازار فارکس است.
