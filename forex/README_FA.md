# پنج سال دادهٔ فارکس برای بک‌تست

این مسیر **سه جفت‌ارز نقدی فارکس** را از Dukascopy برای بازهٔ `2021-11-12T00:00:00Z` تا `2026-11-12T00:00:00Z` (انتهای غیرشامل، پنج سال تقویمی) دریافت می‌کند:

- `EURUSD` (EUR/USD)
- `GBPUSD` (GBP/USD)
- `USDJPY` (USD/JPY)

داده **واقعیِ تاریخی** از فید Dukascopy است؛ نه دادهٔ مصنوعی. نسخهٔ CLI: `dukascopy-node@1.51.1`. مشخصات و دستورات: https://www.dukascopy-node.app/config/cli

## پیش‌نیاز و دانلود

Node.js و npm/npx (برای CLI) و Python 3.11+ (برای پردازش) لازم‌اند. از ریشهٔ ریپو:

```bash
python forex/download_forex.py
python -m unittest discover -s forex -p 'test_*.py' -v
```

اسکریپت دادهٔ ۱ دقیقه‌ای را در بازه‌های ماهانه دریافت، هر CSV را از نظر OHLC، ترتیب زمانی و محدودهٔ UTC بررسی، فایل‌ها را cache و پس از قطع اتصال از همان ماه‌های دانلودشده ادامه می‌دهد. سپس از **همان کندل‌های واقعی** تایم‌فریم‌های 1h و 4h را روی مرزهای UTC می‌سازد. داده‌ها زیر `forex/data/` ذخیره می‌شوند و عمداً در Git commit نمی‌شوند. خروجی در `forex/data/ohlcv/` است:

```text
EUR_USD_bid_1m.csv    EUR_USD_bid_1h.csv    EUR_USD_bid_4h.csv
GBP_USD_bid_1m.csv    GBP_USD_bid_1h.csv    GBP_USD_bid_4h.csv
USD_JPY_bid_1m.csv    USD_JPY_bid_1h.csv    USD_JPY_bid_4h.csv
```

ستون‌ها، دقیقاً مانند فرمت OHLCV پروژه:

```csv
timestamp,open,high,low,close,volume
```

`timestamp` یونیکس به میلی‌ثانیه UTC و زمان **باز شدن** کندل است؛ 1h و 4h روی مرزهای UTC تجمیع می‌شوند. برای تولید داده ask جداگانه:

```bash
python forex/download_forex.py --side ask
```

برای بازهٔ محدودتر یا انتخاب یک نماد:

```bash
python forex/download_forex.py --start 2025-01-01 --end 2026-01-01 --pairs EURUSD
```

### نکات مهم تست ربات

- **فاصله‌های آخر هفته و تعطیلات با کندل جعلی پر نمی‌شوند**. گپ‌ها ممکن است طبیعی یا نقص منبع باشند؛ فیلد `non_consecutive_intervals` آن‌ها را می‌شمارد، اما به‌تنهایی علت را تعیین نمی‌کند.
- `volume` نمایندهٔ حجم مظنه/فید Dukascopy است، **حجم معاملات متمرکز بازار فارکس نیست**. استراتژی وابسته به حجم باید جداگانه ارزیابی شود.
- پیش‌فرض، کندل‌های **bid** است. برای بک‌تست اجرایی دقیق باید ask/spread متغیر، کارمزد کارگزار، rollover/swap، لغزش و محدودیت‌های lot/tick را نیز مدل کنید.
- کندل‌های 1h/4h ممکن است بخشی از دقیقه‌های جلسه را داشته باشند؛ شمار `partial_buckets` در manifest گزارش می‌شود. در صورت نیاز، آن‌ها را در موتور بک‌تست فیلتر کنید.
- `forex/data/manifest_bid.json` برای هر فایل ماهانه و خروجی checksum SHA-256، شمار ردیف‌ها و اولین/آخرین timestamp را ذخیره می‌کند.
- ربات‌های فعلی پروژه مشخصاً برای قراردادهای کریپتو و صرافی LBank نوشته شده‌اند. این مجموعه یک **ورودی دادهٔ سازگار از نظر ستون** است؛ معادل اتصال اجرایی فارکس یا اجرای تاییدشدهٔ بک‌تست سه‌ربات نیست. برای تست قابل اتکا باید نمادها، تقویم بازار، و مدل هزینه/ریسک تطبیق داده شوند.

در محیط اجرای این تغییرات، اتصال خروجی شبکه به منبع برای دانلود عملی برقرار نبود؛ بنابراین **داده‌های پنج‌ساله هنوز در مخزن بارگذاری یا به‌صورت واقعی validate نشده‌اند**. فقط خود pipeline و تست‌های آفلاین ثبت شده‌اند. هیچ نتیجهٔ بک‌تستی ادعا نمی‌شود.
