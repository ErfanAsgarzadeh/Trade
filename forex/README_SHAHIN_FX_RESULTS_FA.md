# شاهین فارکس — نتیجهٔ بک‌تست پنج‌ساله (EURUSD، GBPUSD، USDJPY)

**بازه:** 2021-11-12 تا 2026-11-06 (آخرین دقیقهٔ موجود)، دادهٔ واقعی ۱ دقیقه‌ای bid از HistData.com، حدود ۱٫۸ میلیون دقیقه برای هر جفت‌ارز.
**حساب:** یک حساب مشترک ۱۰٬۰۰۰ دلاری برای هر سه جفت‌ارز (نتیجه در سطح سبد است، نه هر جفت جدا).

> فید Dukascopy از شبکهٔ این محیط در دسترس نبود و اتصال‌ها reset می‌شدند. برای همین `download_histdata.py` اضافه شد. HistData قیمت‌ها را به وقت EST ثابت (UTC−5) می‌دهد و این اسکریپت آن‌ها را به UTC تبدیل می‌کند. ساعت تکراریِ تغییر ساعت پاییزی حذف می‌شود (فقط سطرهای کاملاً یکسان). هیچ کندل ساختگی‌ای اضافه نمی‌شود.

## اجرا

```bash
pip install numpy pandas numba
python forex/download_histdata.py
python -m unittest forex/test_shahin_fx.py -v
python forex/run_shahin_fx.py          # حدود ۷ دقیقه روی ۴ هسته
```

خروجی‌ها در `forex/reports/` قرار می‌گیرند: `shahin_fx_5y.json` (گزارش کامل)، `shahin_fx_5y_winner_trades.json` (فهرست معاملات و منحنی سرمایهٔ برنده) و `stage1_top300.json`.

بخش‌های مشترک با شاهین کریپتو: ورود با شکست Donchian10 و تأیید بیرون بودن قیمت از Kumo استاندارد، استاپ اولیه 2×ATR، فیلتر رژیم ATR60، و توقف ورود پس از زیان ۲٪ در ۲۴ ساعت. اجرای سفارش‌ها، استاپ‌ها، سواپ و افت سرمایه با دقت دقیقه‌ای شبیه‌سازی می‌شود.

## جستجو

- **مرحلهٔ ۱:** ۱۱٬۵۲۰ ترکیب. ابعاد جستجو: تایم‌فریم 1h/4h/D1، پریست ایچیموکو (standard، crypto یا بدون Kumo)، Donchian 10/20/55/100، ATR 1.5/2/3، چهار نوع تریل، و روشن/خاموش بودن کف سود، گیت ATR، هرمی، فیلتر سشن و بستن پوزیشن‌ها پیش از آخر هفته.
- **مرحلهٔ ۲:** ۷۲۰ ترکیب حول پنج گزینهٔ برتر. ابعاد: ریسک، USD cap، پارامترهای کف سود و حداقل استاپ.
- **معیار انتخاب:** بیشترین Calmar (CAGR تقسیم بر بیشترین افت سرمایه بر مبنای ارزش لحظه‌ای)، به شرط دست‌کم ۴۰ معامله و CAGR مثبت.

|---|---|---|---|---|---|
| **۱٪** (هم‌اندازهٔ شاهین کریپتو) | **۴٫۵٪** | **۵٫۴٪** | ۰٫۸۴ | +۲۴٫۸٪ | ۱۲٬۴۷۶ دلار |
| ۱٫۵٪ | ۶٫۹٪ | ۸٫۲٪ | ۰٫۸۵ | | |
| ۲٪ | ۹٫۲٪ | ۱۰٫۹٪ | ۰٫۸۵ | +۵۵٫۳٪ | ۱۵٬۵۳۱ دلار |
| ۳٪ | ۱۳٫۱٪ | ۱۵٫۹٪ | ۰٫۸۲ | | |

برای ریسک ۲٪: ۵۲ معامله، نرخ برد ۶۷٪، Profit Factor برابر ۲٫۲۴ و Sharpe برابر ۰٫۷۷.

بازده سالانه با ریسک ۱٪: سال ۲۰۲۲ ‎+۱۴٫۶٪، سال ۲۰۲۳ ‎+۴٫۸٪، سال ۲۰۲۴ ‎+۳٫۴٪، سال ۲۰۲۵ ‎+۲٫۳٪ و سال ۲۰۲۶ ‎−۱٫۸٪.

سهم هر جفت‌ارز (ریسک ۲٪): USDJPY ‎+۴٬۳۴۸، EURUSD ‎+۱٬۸۷۵ و GBPUSD ‎−۶۹۱ دلار. حدود ۹۰٪ سود USDJPY از پوزیشن‌های لانگ سال‌های ۲۰۲۲ و ۲۰۲۳ آمده است.

## آزمون‌های اعتبار: لطفاً پیش از استفاده بخوانید

1. **تست خارج از نمونه (Walk-forward):** گزینه‌ها فقط با دادهٔ 2021-11 تا 2024-12 انتخاب و سپس روی 2025-01 تا 2026-11 تست شدند. **هر ۱۰ گزینهٔ برتر داخل نمونه، خارج از نمونه زیان دادند** (CAGR بین −۲٫۴٪ و −۸٫۶٪). خود برنده هم در دورهٔ ۲۰۲۵ تا ۲۰۲۶ عملکرد CAGR ‎−۲٪ و افت سرمایهٔ ۱۰٫۷٪ داشت (با ریسک ۲٪).
2. **حساسیت به پارامترها:** تغییر یک‌مرحله‌ای پارامترها Calmar را از ۰٫۸۵ به بازهٔ ۰٫۰۵ تا ۰٫۶ می‌رساند. بیشترین افت هنگام روشن کردن بستن آخر هفته، تغییر پریست ایچیموکو یا ATR3 دیده شد. یعنی نتیجه روی یک نقطهٔ نسبتاً تیز از فضای پارامترها نشسته است.
3. **حساسیت به هزینه‌ها:** کم است. حتی با دو برابر کردن اسپرد، لغزش ۱ پیپ و کمیسیون ۱۰ دلار، CAGR از ۹٫۲٪ فقط به ۸٫۹٪ می‌رسد، چون تعداد معاملات کم است. ریسک اصلی **ضعیف بودن خود لبه** است، نه هزینه‌ها.
4. **کم بودن نمونه:** ۵۲ معامله در پنج سال است و بخش بزرگی از سود به روند صعودی USDJPY در ۲۰۲۲ و ۲۰۲۳ وابسته است.

**جمع‌بندی:** نسخهٔ فارکس به‌مراتب بهتر از انتقال مستقیم شاهین کریپتو است (به‌جای ‎−۹٫۶٪ و افت ۵۵٪، ‎+۴٫۵٪ با افت ۵٫۴٪). اما «بهترین نتیجهٔ پنج‌ساله» یک انتخاب درون‌نمونه است و تست خارج از نمونه آن را تأیید نمی‌کند. پیش از هر استفادهٔ واقعی، اجرای paper و افزودن جفت‌ارزهای بیشتر (برای بزرگ‌تر شدن نمونه) توصیه می‌شود. پیکربندی ربات زنده (`lbank_project`) تغییری نکرده است.

## محدودیت‌های مدل

- دادهٔ HistData فقط bid است. اسپرد ثابت و میانگین فرض شده و گشاد شدن اسپرد هنگام rollover یا انتشار اخبار مدل نشده است.
- نرخ‌های بهره برای محاسبهٔ سواپ تقریبی‌اند (`POLICY_RATES` در `shahin_fx.py`) و نرخ‌های پس از اواخر ۲۰۲۵ ثابت نگه داشته شده‌اند.
- ترتیب رخدادها درون یک دقیقه شبیه‌سازی نمی‌شود: اگر قیمت در یک دقیقه از سطح استاپ عبور کند، فرض می‌شود استاپ (یا قیمت بازشدن، اگر بدتر باشد) اجرا شده است. مارجین‌کال کارگزار مدل نشده است.
- فاصلهٔ زمانی ماه‌های فوریه تا ژوئیهٔ ۲۰۲۳ در EURUSD دقیقه‌های کمتری دارد، چون در منبع داده دقیقه‌های بدون تیک ثبت نشده‌اند. این دقیقه‌ها گپ واقعی نیستند.
