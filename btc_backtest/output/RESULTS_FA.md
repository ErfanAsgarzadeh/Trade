## بازتولید
در پوشهٔ بسته و با Python 3.11+:
```bash
pip install -r btc_backtest/requirements-backtest.txt
python btc_backtest/download_data.py
python btc_backtest/backtest.py
cd btc_backtest
python -m pytest test_backtest.py -q
python make_report.py
```
برای نمودار matplotlib لازم است. آرشیوهای خام بازار داخل این بسته نیستند و دانلودکننده آن‌ها را از منبع رسمی می‌گیرد. فایل data_manifest.json checksum دادهٔ این اجرا را نگه می‌دارد.
