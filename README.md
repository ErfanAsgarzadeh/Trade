## بازیابی داده‌ها برای اجرای آفلاین

```bash
python restore_data.py
```

`data_parts/` تمام آرشیوهای خام، checksumها، features.npz و دفترهای باینری را در قطعات24MiB نگه می‌دارد. این دستور SHA-256 هر قطعه و ZIP کامل را کنترل و مسیرهای اصلی را بازیابی می‌کند. سپس راهنمای portfolio/README_FA.md را دنبال کنید. پوشش خام756آرشیو اصلی و10آرشیو روزانه بازیابی است؛ SOL/XRP هرکدام پنج روز از آرشیو ماهانه کم داشتند و با روزانه رسمی تکمیل شدند. prepared/ محاسبات مشتق‌شدهٔ قابل بازتولید است و برای جلوگیری از تکرار حجیم، در بسته ورودی تکرار نشده است.

ربات در حالت paper باقی می‌ماند. بک‌تست کارمزد0.12% رفت‌وبرگشت، لغزش2bps هرFill و Funding را دارد؛ Funding چهار روز انتهایی فرضی است. precision تاریخی و liquidation/Mark Price تاریخی بازسازی نشده‌اند؛ جزئیات و sensitivity در گزارش آمده‌اند. فایل‌های محرمانه، دیتابیس اجرای محلی و وابستگی‌های نصب‌شده وارد مخزن نشده‌اند.
